## 定位与主线

- 承接概念篇结尾的预告："下一篇顺着 Harness 往下挖：Skills、MCP、hooks、插件、子智能体、指令……"。开场要点破这个承接。
- 核心判断（开场尽早给出）：这六个名词不是六个竞品，是六种不同层的装备，各管一件事——**指令管"记住"，Skills 管"会"，MCP 管"够得着"，Hooks 管"必须"，插件管"打包"，子智能体管"分身"**。
- 贯穿比喻（全文唯一，不得中途混用）：把接入 agent 当成"给一位聪明的新同事配装备"。指令=入职须知（说了未必照做）、Skills=岗位手册（用到才翻）、MCP=内部系统工牌（够得着公司系统）、Hooks=门禁卡（物理拦下）、插件=整套装备的安装包、子智能体=另开一间办公室的小组。此比喻只做辅助注解，主体仍是机制讲解，别让比喻淹没事实。

## 大纲

### 1. 开场：装好 agent 的第一天（钩子）
- 场景：你兴冲冲装好一个编码 agent，一天内连吃三次闭门羹：它不懂你们团队的发布流程；它说"我连不上你们的工单系统"；它口头答应"不跑危险命令"，转头还是跑了。
- 三个场景分别对应三类缺口：不会（知识）、够不着（连接）、不保证（纪律）。
- 尽早给核心判断（上面那句话），上全景图（配图1）。
- 点破承接：概念篇说过"模型聪明但没有手"，这篇讲的就是那双手怎么装、以及怎么让它守规矩。

### 2. 指令：说了，但它未必照做
- 是什么：常驻上下文的 Markdown 文件。CLAUDE.md 四层体系（调研§一#28）；AGENTS.md——"给编码代理看的 README"、60k+ 项目（官方站自报口径）、2025-08 上线、现由 AAIF 托管（§一#30）；Cursor 转向 `.cursor/rules/*.mdc`（2025 年起，避免精确版本号 §三#3）。
- 关键定性（本文最重要的一句，官方原话）："Claude treats both as context, not enforced configuration"——指令是上下文，不是强制配置（§一#29）。
- 用法建议：写规范不写百科；Cursor 官方建议"规则少于 500 行、引用文件而非粘贴"（注明是 Cursor 一家之言）。
- 记忆点：**指令影响判断，不提供保证。**

### 3. Skills：用到才翻的岗位手册
- 是什么：一个文件夹 + SKILL.md（frontmatter 必填 name/description），Anthropic 2025-10-16 发布（§一#18）；2025-12 开放为标准 agentskills.io，40+ 客户端（§一#19、#20）。
- 三级渐进式加载：启动只载名称与描述 → 判断相关才读全文 → 按需读捆绑脚本/文件（§二）。这是它和指令的本质区别：常驻 vs 按需，省的是上下文预算。
- 与 MCP 分工（Anthropic 口径）：Skills 教"怎么用"，MCP 管"连上"（§二）。
- 记忆点：**指令是每天都读的员工守则，Skills 是用到才翻的岗位手册。**

### 4. MCP：内部系统的工牌
- 是什么：开放协议，2024-11-25 Anthropic 发布（§一#1）；官方类比"AI 应用的 USB-C"（§二）。
- 机制三句话：Host 里跑 Client，每个 Server 一个连接；三大原语 tools/resources/prompts（§一#10、#11）。sampling 已在 2026-07-28 版规范弃用——别沿用旧资料（§三#6）。
- 时间线（可口头叙述，最终进大事记表）：2025-03 OpenAI 采用 → 2025-04 Google → 2025-05 Microsoft（Windows 原生支持）→ 2025-12-09 捐给 Linux 基金会 AAIF（创始项目 MCP、goose、AGENTS.md）（§一#13–16）。
- 规模数字必须标口径：97M+ 月 SDK 下载、10,000+ 公开服务器，均为 Anthropic 2025-12 公告自报口径（§一#17、§三#5）。
- 记忆点：**MCP 管的不是聪不聪明，是够得着够不着。**

### 5. Hooks：门禁卡
- 是什么：在生命周期固定点自动执行的用户定义命令；事件从 2025-06 首发约 4 个涨到现在约 30 个（第三方 changelog 追踪口径，正文写"2025 年 6 月底"避免精确版本号，§三#2）。
- 关键语义：exit 2 = 阻断；官方原话："If your hook is meant to enforce a policy, use exit 2"；以及"要硬保证某动作被拦下，就用 PreToolUse hook"（§一#21–23、§二）。
- 与指令的本质对比收束上一节伏笔：指令靠自觉，Hooks 靠机制。配图3。
- 记忆点：**要"必须"，就得用门禁，不能靠墙上贴的守则。**

### 6. 插件：把装备打包成安装包
- 是什么：plugin.json 清单 + skills/agents/hooks/.mcp.json，2025-10-09 公开 beta；官方称"今后打包分享 Claude Code 定制的标准方式"（§一#24、#25）。
- marketplace 只是"列插件的 git 仓库"，不是托管商店（§二）。
- 安全提醒（官方原话口径）："plugins run as you"——装第三方插件前要审查（§二）。
- 记忆点：**插件不是新能力，是把前几样装备打包装进一个快递箱。**

### 7. 子智能体：另开一间办公室
- 是什么：独立上下文窗口、独立系统提示词与工具白名单，可并行、可嵌套（约三层，官方文档口径），配置在 `.claude/agents/*.md`（§一#26）。首发时间写"2025 年 7 月"（§三#2）。
- 什么时候用：大任务隔离（防止搜资料把主对话上下文污染）、并行干活、专业分工（测试审查员等固定角色）。
- 记忆点：**子智能体是另开一间办公室：信息隔离，各干各的，汇报走正式渠道。**

### 8. 六件装备怎么配合
- 一个场景串起来：给团队项目配一套——CLAUDE.md 立规矩、Skill 装发布流程、MCP 连工单系统、Hook 卡住危险命令、插件整体分发给同事、子智能体跑批量审查。
- 对照表（六行：装备｜管什么｜一眼认出它）。
- 呼应概念篇 harness 解剖：指令/记忆=上下文层、MCP=工具连接层、Skills=知识层、Hooks=控制层、插件=分发层、子智能体=编排层；官方佐证：Claude Agent SDK 能力表（§一#32）。
- 国内视角一段：DeepSeek 官方 Anthropic 兼容端点接 Claude Code、Qwen Code 内置 MCP/子智能体/Skills、GLM Coding Plan 官方兼容 20+ 工具——机制是通用协议，模型可插拔（§一#33–35）。**不要提"DeepSeek App 支持 MCP"（未核实，§三#1）。**

### 9. 写在最后
- 只收束一次：六件装备对应四类缺口（不会/够不着/不保证/要分发）——装齐了，新同事才真正能上岗。
- 下篇预告：装备配好了，还没上手的朋友从哪开始？下一篇写新手入门路线。
- 题外话：一句个人化的话（参考概念篇结尾风格）。

## 定位与主线

- 读者画像：没用过 agent 的中文读者，一部分不写代码，一部分是开发者；相当一部分在中国大陆（支付与可访问性必须交代）。
- 核心判断（开场尽早给）：上手 agent 不难，难的是两件事——选对第一站、把需求说清楚。路线五步：想清楚要它干嘛 → 选第一站 → 装起来 → 说清需求 → 建立安全与费用预期。
- 叙事口吻：带一位具体的朋友走一遍（口语化、对读者说话，参考概念篇"做个小实验"的笔法）。
- 与概念篇衔接：agent/模型/harness 的定义不重讲，一句话带过并链接概念篇。

## 大纲

### 1. 开场：朋友问你怎么上手，你从哪说起（钩子）
- 场景：朋友看你用 agent 半天干完一天的活，问你"这东西怎么上手"。你打开手机才发现，要解释的不是一款 App，而是一整套东西——网页里能聊的、终端里能跑的、订阅的、按量付费的。
- 尽早给路线图（五步）+ 核心判断。配图1（决策图）放本节末。

### 2. 第一步：想清楚要它干嘛
- 一句话区分（引概念篇）：聊天是"你问它答"，agent 是"下一步由它自己决定"。
- 两条入手路径由这个区别决定：不想装任何东西 → 网页对话里的 agent 能力（免费档起步）；愿意开终端、想让它直接在你电脑上干活 → 本地 CLI agent（调研§五）。
- 提醒：两类不是二选一，多数人最终两个都用。

### 3. 第二步：选第一站
- 决策三问：写不写代码？在哪付费方便？预算多少？
- 候选表（**只用调研表中"官方页已核"的数字**，见红线）：Claude（网页+Claude Code，Pro $17–20/月）、Codex（CLI 安装命令已核，价格档位写"以官网为准"）、Gemini（app 免费档，CLI 免费层 2026-06-18 起移交 Antigravity CLI）、DeepSeek（网页免费，API 按量人民币、错峰半价）、Qwen Code（安装命令已核）、智谱 GLM Coding（海外 Lite $18/月起；国内价以购买页为准）、Kimi（Plus ¥99 起，含 Kimi Code）。
- 按人群给三条明确推荐（标明是作者建议）：不写代码、先白嫖练手 → 国内网页端免费档（DeepSeek/豆包/元宝）；写代码、大陆付费 → Kimi Plus / GLM / Qwen Code / DeepSeek API；有国际支付 → ChatGPT Plus 或 Claude Pro（约 $20/月档）。

### 4. 第三步：装起来
- 以 Claude Code 为例给官方安装命令（curl / PowerShell / winget，调研§一，已核）；提一句 Node 22+、勿用 sudo（官方口径）。
- 首次运行会发生什么：登录、权限询问——顺势预告第 6 节权限话题。
- 网页端零安装对照一句。

### 5. 第四步：把需求说清楚
- 四条官方依据（都出自 Claude Code 官方 best practices 与 Anthropic agents 指南，可直引并给链接，调研§二）：
  1. 说得越精确，返工越少（"The more precise your instructions, the fewer corrections you'll need"）；
  2. 给上下文：指名文件、约束条件、参考例子；
  3. 先计划后执行：Explore → Plan → Implement → Commit；大任务先让它采访你写 SPEC；
  4. 给它一个能跑的检查：测试、构建、截图对比（"Give Claude a check it can run"）。
- 好需求 vs 差需求对照（表格或并列示例，作者撰写，标明是示例）。
- 顺手两条官方习惯：纠正两次以上就开新会话；不相关任务之间清空上下文。

### 6. 误区与边界
- 权限：Claude Code 六种权限模式里挑重点讲（默认询问 / plan 只读 / bypassPermissions 官方原话警告"仅在容器或虚拟机等隔离环境使用"，调研§二）；沙箱一句（OS 级限制，纵深防御官方口径）。
- 数据安全：订阅前检查"对话是否默认用于训练"——Anthropic 消费者条款已核（默认可用于训练、设置里可退出、点赞过的对话仍可能用于训练）；OpenAI 给链接并注明"以官方页为准"（调研§四）。
- 费用预期：订阅=固定月费换"5 小时窗口+周额度"（各家官方口径一致）；API=按 token 计量，Kimi 官方单次成本示例（简单约 ¥0.03、复杂多步约 ¥1.6）与 DeepSeek 错峰半价可直接引用（官方已核）；别以为订阅=无限量（ChatGPT agent 模式限额极小——"限额极小"模糊表述，具体数字未核实不写）。
- 常见误区清单（5-7 条，来自调研§三，每条能标出处或标"作者建议"）：一次丢超大任务、不复核就用、把对话窗口当数据库、重要环境乱开免询问、没备份就让它改文件。

### 7. 写在最后
- 只收束一次：第一周练手路径一句话带过（读代码提问 → 改一个小函数 → 让它自己跑测试），别等"学会了"再开始。
- 下篇预告：工具上手了，模型怎么挑？下一篇聊 2026 年秋天的模型横评。
- 题外话：一句个人化收尾。

## 选题清单

### 1. 核心概念:AI、模型、Agent、Harness

- 解释这些概念分别是什么
- 它们的由来(怎么被提出、命名的)
- 概念之间的演变过程与相互关系

### 2. AI 使用生态:Skills、MCP、Hooks、插件、子智能体、指令

- 各个概念的解释:是什么、解决什么问题
- 怎么使用:典型用法与实践
- 它们之间的关系与配合方式

### 3. 个人经历:使用 Agent 的感悟

- 我自己使用 agent 的真实经历
- 踩过的坑与经验总结
- 对人机协作方式的思考

### 4. 新手引导:怎么开始用 Agent

- 面向没用过 agent 的读者,给一条从零开始的入门路径
- 第一个 agent 怎么选、怎么装、怎么把需求说清楚
- 常见误区与边界:权限、数据安全、费用预期

### 5. 模型横评:不同模型的区别与擅长领域

- 主流模型的定位差异(以动笔时点为准,时效性强)
- 按擅长领域对比:编程、画图、写作、长文本等
- 怎么按任务选模型,多模型混合使用的思路

### 6. Harness 横评:不同的 Agent 外壳

- 主流 harness 的定位与差异(终端 / IDE / 网页等形态)
- 各自的交互方式、扩展机制、适合的人群
- 与选题 1 的概念篇呼应,偏实操对比

### 7. 我的 AI 工具箱

- 日常在用的 AI 相关工具盘点(agent、模型服务、周边工具)
- 每个工具解决什么问题、为什么留下它
- 工具之间怎么组合成自己的工作流

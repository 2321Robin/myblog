## 三种可选方案

| 方案 | 结构 | 优点 | 代价 |
| --- | --- | --- | --- |
| A 分组导航工作台（推荐） | 简短身份介绍 + 常用工具 + 内容与社交分组 + 近期文章 | 工具立即可见，保留个人站辨识度，兼顾移动端 | 需要重排首页和抽离入口数据 |
| B 紧凑网址目录 | 所有入口以列表或小卡片集中展示，介绍退居页脚 | 一屏容纳更多入口，浏览效率高 | 个人内容和作品表现力较弱 |
| C 搜索启动器 | 大搜索框和少量快捷入口为中心 | 熟悉站点的回访用户定位快 | 首次访问需要探索，当前入口数量不多，搜索不宜独占首屏 |

建议采用 A，并提供轻量站内入口搜索，不将搜索作为唯一导航方式。

## 推荐设计

### 页面结构

```text
Robin / 个人站点       工具与站点 · 文章 · 关于       主题切换

你好，我是 Robin。
我的工具、作品与记录，都在这里。
简短原有介绍                         搜索站点与工具 [      ]

常用工具与站点
[打牌计分]    [扫雷游戏]    [在线简历]    [个人项目集合]
 图标、简述、域名、外链提示；整张入口卡片可点击

内容与社交                             其它入口
博客 · 标签 · GitHub · B站 · CSDN       主域名 · 访问统计

近期文章：真实文章日期、标题、摘要；全部文章与 RSS
关于：保留原有两段介绍、技术背景、邮箱
版权、ICP备案、公安备案和原有图标
```

桌面内容宽约 1120–1200px，常用入口四列。平板两列；手机根据可用宽度排列一至两列，文案完整可读。手机保留直接可用的分区导航，避免为了四个链接增加复杂抽屉。

### 视觉方向

采用清晰、轻盈的蓝灰界面，以站点入口本身建立视觉识别。

- 背景 `#F3F6FB`，卡片 `#FFFFFF`，主文字 `#18233B`。
- 主色 `#4255CF`，辅助青色 `#157A83`，边框 `#DCE3EE`。
- 深色主题使用深蓝背景与明亮的浅蓝主色，并逐一检查文字、按钮和边框对比。
- 中文正文用本地中文无衬线字体；Robin 标识采用有分量的英文显示字形；域名与日期采用等宽字体。本轮避免依赖远程字体下载。
- 常规文字 15–16px，正文 16–18px，首页标题随视口变化约 32–52px；避免中文标题过紧字距。
- 卡片圆角约 16–20px，单层容器、克制阴影。保留现有图标库，入口使用一致尺寸的图标。
- 识别细节：工具卡片底部直接展示真实域名，方便在多个子站之间辨认；不虚构访问量、在线状态或项目截图。
- 动效限于焦点、悬停和短暂状态反馈，遵守减少动画偏好。

### 组件与数据

- `site-links` 数据模块集中保存入口名称、地址、描述、分类和图标标识。组件不得各自维护重复 URL 列表。
- `SiteHeader` / `SiteFooter` 提供统一导航、主题和原有备案信息，博客子页保持一致。
- `SiteDirectory` 负责首页入口展示和本地过滤。只把该交互区域设为客户端组件，MDX 加载仍在服务端。
- 输入框有可见标签；按标题、描述和域名过滤，支持中文名称与英文名称。搜索状态使用 `?q=`，刷新与后退可恢复。分组始终对应真实用途。
- 零结果显示查询词、“清除搜索”操作；结果数使用 aria-live。无 JavaScript 时仍可看到完整入口列表。
- 链接卡片使用原生链接；整卡片不得嵌套按钮。外链遵循一致的新窗口策略，邮箱直接调用邮件应用。
- 博客列表、标签页和文章页应用统一视觉，修复已定位的网格、标题、列表标记与日期方向文案问题。
- 原有搜索索引接口保留；博客全文搜索不纳入本轮必要范围，README 按实际功能描述。
- 本轮只处理现有仓库，不创建新的托管项目或部署。
